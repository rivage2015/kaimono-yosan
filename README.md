# 買い物予算メモ

公開URL：https://kaimono-yosan.netlify.app/

日本語のスマートフォン向け静的Webアプリです。外部ライブラリ、アカウント、API、分析送信はありません。金額欄を押すと大きなテンキーが開きます。数字・1文字消去・確定を使え、閉じる/外側タップ/標準キーボード切替でも入力値を保持します。標準キーボードの種類やフリック入力は端末の設定によります（サイトから強制しません）。スマートフォンでは自作テンキー中に標準キーボードを出さず、デスクトップでは物理キーボードも使用できます。税込の整数円を入力し、数量を選んで追加します。商品名は任意です。

## ローカルで試す

このフォルダで次を実行し、Chrome等で http://127.0.0.1:8765 を開きます。

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory public
```

ファイルを直接開く方法ではサービスワーカーを利用できません。初回は通信が必要です。「オフラインで使えます。」の表示後、同じブラウザ・同じURLでオフライン利用できます。スマートフォンでの本格検証はNetlifyのHTTPS公開後に行います。

## Netlifyの手動配備

1. 本人のNetlifyアカウントで手動デプロイ画面を開きます。
2. `shopping-budget-memo-netlify.zip` を展開します。
3. 展開した `public` フォルダをアップロードします。`index.html` が公開フォルダの直下にある構造です。ビルドコマンドは不要です。
4. 発行されたHTTPSのURLをスマートフォンで開き、初回キャッシュ完了表示を確認します。
5. 機内モードで再度開き、保存・復元と予算を確認します。

更新時は `public/sw.js` の `CACHE` の版番号を変更して同じサイトへ配備します。買い物中のタブを強制更新せず、全タブを閉じて開くと更新されます。端末内データのキーは変更しません。公開URLやブラウザを変えると保存領域が別になります。

## ファイルとデータ

- `public/index.html`：画面と確認ダイアログ
- `public/style.css`：モバイル向けの表示
- `public/app.js`：計算・操作・端末内保存
- `public/sw.js`：オフラインキャッシュ
- `public/_headers`：NetlifyのHTTPヘッダー
- `tests/`：Chrome自動テスト（個人環境の絶対パスに依存しない）
- `evidence/mobile-320.png`：320px幅のChromeエミュレーション

現在のカートと予算をlocalStorageに保存します。履歴はありません。終了時に確認して品目だけを消します。削除直後は8秒間取り消せます（次の削除で対象は置き換わります）。ブラウザのデータ削除・プライベートブラウズ・容量制限では保存が消えたり失敗したりするため、保存失敗時は画面に表示します。複数タブで同時編集する使い方は対象外です。

価格・予算は0以上、数量は1以上の半角整数です。乗算と合計がJavaScriptの安全な整数範囲を超える操作は拒否します。外部フォントは使いません。

## 開発用テスト（任意）

アプリ利用・Netlify配備にはNode.jsやnpmは不要です。テストのみ、Node.jsのある環境で `npm install` を行い、上記ローカルサーバーを起動した状態で `npm test` を実行します。macOSはインストール済みGoogle Chromeを使います。他のOSは `npx playwright install chromium` を実行するか、環境変数 `CHROME_EXECUTABLE` にChromeの実行ファイルを指定します。SW更新テストは一時的に版番号を書き換えて元に戻すため、テスト中は配備しないでください。
